### 👋 Hey there

I'm an **Associate Cloud Engineer at Elite Cloud**, a multi-cloud CSP partner.

I got here the long way round: I started in **cybersecurity in 2019**, founded and led the CTF team **EliteSploit**, wrote offensive and defensive security content for **BowTiedCyber**, and still compete with **Federal Bonk Investigations**. Now I'm combining both worlds, and the goal is clear: **cloud security engineering**.
